Jev RTT Demo

Single-page, fully client-side demo for the TypeSafe System One API (jev-latest). API reference: docs.typesafe.ai/introduction/quickstart

Connection

RTT measurement (IPv4)

Measured with fetch(..., {mode:'no-cors'}) — no API key required; the response itself is opaque, but the request fully round-trips the server. api.typesafe.ai is IPv4-only (no AAAA record). Point this at /api/v1/systemone to measure the proxied path instead.
Idle.
Timer: performance.now() (~0.1 ms effective resolution). First request includes TCP+TLS handshake; subsequent requests reuse the keep-alive connection (HTTP/2), so warmup samples are discarded from the stats.
