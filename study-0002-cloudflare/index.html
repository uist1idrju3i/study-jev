Jev Cloudflare Demo

Single-page, fully client-side demo for typesafe/jev on Cloudflare Workers AI. Model docs: developers.cloudflare.com/ai/models/typesafe/jev

Connection

RTT measurement

api.cloudflare.com is dual-stack (A + AAAA), but browsers cannot pick the address family of a fetch(). Instead, serve.py resolves the host restricted to the chosen family, connects with correct SNI/Host, and times each phase with time.perf_counter(): DNS, TCP connect, TLS handshake, TTFB and total. With keep-alive on (default), warmup requests establish a persistent connection and later samples measure pure HTTP round-trips.
Idle.
Stats cover successful samples' total_ms (request sent → last byte), measured inside serve.py — no browser or localhost-hop noise. The status line shows the latest sample's phase breakdown and the resolved upstream IP.

    Browser → api.cloudflare.com direct calls fail CORS: the preflighted
    Authorization header gets 405 back with no
    Access-Control-Allow-Origin. Serve this page via python3 serve.py
    (http://localhost:8000) so calls are relayed same-origin through
    /api/*. Your token and account ID travel only to your own localhost proxy —
    nothing is persisted. Note that plain python3 -m http.server 8000 serves the
    page but cannot proxy, so the demo call still needs serve.py.
